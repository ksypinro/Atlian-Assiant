# Slack listener for Jira / Confluence updates (DM-32 / DM-33)

Atlassian's own Slack apps post issue and page updates into a channel. A small, **read-only** Slack app of yours listens to that channel over
**Socket Mode** (an outgoing WebSocket, so no public URL is needed) and turns each message into an event. The library then reads the real issue
or page through REST, because the Slack text is only a hint.

```
Jira / Confluence change → Jira Cloud / Confluence Cloud Slack app posts in #kan-updates
  → your "atlassian-events" app (Socket Mode, read-only) → SlackSocketModeSource → REST read of the issue / page
```

## Files

| File | Use |
|---|---|
| `atlassian-events-manifest.json` | Paste into Slack when creating the app (**public** channels) |
| `atlassian-events-manifest.private-channels.json` | Use instead if the channel is **private** (adds `groups:history`, `groups:read`) |
| `listen.py` | Starts the listener and prints each update with the issue's real summary and status |

The manifests are generated by `atlian_assiant.events.provision.slack.socket_mode_manifest()`. A test keeps them equal, so don't edit them by hand.

## Steps (you do these; they need your Slack and Atlassian logins)

1. **Atlassian apps → channel.** In Slack: *Apps → add* **Jira Cloud** (and **Confluence Cloud** if wanted), connect them to
   your site (`your-site.atlassian.net`). Create a channel, e.g. `#kan-updates`, add the app, then run `/jira connect` / `/jira subscribe`
   (pick project `KAN`, optional JQL filter). For Confluence: `/confluence subscribe` and pick the space.
2. **Create the listener app.** Go to <https://api.slack.com/apps> → *Create New App* → *From a manifest* → choose your workspace → paste
   `atlassian-events-manifest.json` → *Create*.
3. **Install it** to the workspace (*Install App*). Copy the **Bot User OAuth Token** (`xoxb-…`).
4. **App-level token.** *Basic Information → App-Level Tokens → Generate* with scope **`connections:write`**. Copy it (`xapp-…`).
5. **Invite the bot** into the channel: in `#kan-updates` type `/invite @atlassian-events`.
6. **Channel id.** Open the channel details; the id is at the bottom (looks like `C0123ABCD`).
7. **`.env`** (keep the file private; it is git-ignored):
   ```
   ATLASSIAN_EVENTS_SLACK_APP_TOKEN=xapp-...
   ATLASSIAN_EVENTS_SLACK_BOT_TOKEN=xoxb-...
   ATLASSIAN_EVENTS_SLACK_CHANNELS=["C0123ABCD"]
   ```
8. **Run:** `pip install -e '.[slack]'`, then `python deploy/slack/listen.py`. Change something in a `KAN` issue and watch the channel.
   Personal notifications skip your own changes; if nothing appears in the channel either, make the change as another user.

## What the app can and cannot do

- Scopes: only `channels:history` + `channels:read` (plus `groups:*` in the private variant). It **cannot post, delete or change** anything.
- It reads only the channels in `ATLASSIAN_EVENTS_SLACK_CHANNELS` (allow-list) and ignores its own bot.
- Slack messages can be grouped or late: keep the polling source running as the safety net.
